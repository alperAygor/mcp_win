ArchMCP User Guide

Working with Claude in Revit, AutoCAD, Photoshop and SketchUp.

Back up before you work. With the full authority you granted, Claude can modify and delete your model, drawing and files; some actions (overwrite, delete, merge in Photoshop) are irreversible.

1. Getting started: the ArchMCP control panel

  1. Open ArchMCP from the Start menu or the desktop.
  2. On the Connections page switch on the software you want. Missing application add-ons (Revit, Blender, FreeCAD, Photoshop) are installed automatically.
  3. Press Apply and restart Claude. Claude starts the servers when it launches, so it has to restart once. (An open chat is interrupted; the panel asks first.)
  4. Open your software (see the table below) and start a new chat in Claude; the tools icon of the chat box lists the archmcp-… servers.
  5. Ask in plain language. Claude picks the right tools itself.

In the panel: Test on each card (really starts the server), Details (options, permissions, add-on install), Settings (language, appearance, backups), Diagnostics (test everything at once), Logs. The panel stops by itself when closed; Claude's connections keep working with the panel closed.

3. Authority you granted

SoftwarePermission
RevitRead + create/modify/delete (operations are one undoable transaction in Revit — Ctrl+Z reverts them).
AutoCADRead, modify, delete, purge, save/overwrite. The raw-command restriction is ON: commands that run programs (SHELL, NETLOAD, APPLOAD, VBARUN) are blocked.
Photoshopread, edit, external, destructive — everything by default (file read/write, overwrite, delete, merge). You can narrow it in the panel.
BlenderRuns Python in the live Blender. Safe mode (in the panel) blocks code that uses files, programs or the network.
FreeCAD / Godot / Unity / OpenSCADEdit models/projects/scenes/scripts and (FreeCAD) run Python. For Unity the editor plugin lives inside your project.

Telemetry: the Blender and Unity servers' own (on by default) telemetry is switched off by ArchMCP.

Always review what Claude changed. Text inside files from untrusted sources can mislead Claude.

4. Troubleshooting

First run Start menu → ArchMCP → ArchMCP Doctor; it starts each server the way Claude does and tells you what is missing.

SymptomFix
archmcp-… not shown in ClaudeQuit Claude from the system tray too, then reopen. Doctor checks the "Claude config" line.
Revit: "add-in not reachable"Open Revit with that version (e.g. 2026) and open a project; the add-in loads at Revit start.
Photoshop: "bridge not reachable"Open Photoshop and the Plugins → Photoshop MCP panel. If the plugin is missing, double-click servers\photoshop-plugin\photoshop-mcp.ccx in the install folder and restart Photoshop.
AutoCAD not connectingMake sure AutoCAD 2026 is running with a drawing loaded.
Antivirus deletes filesAdd %LOCALAPPDATA%\Programs\ArchMCP to its exclusions and rerun setup.
Panel does not openMicrosoft Edge or Chrome is required (Edge ships with Windows). Restart ArchMCP from the Start menu; if it still fails run "ArchMCP Doctor".
Unity not connectingIs the package installed in the project (green "installed" in the panel)? In Unity check Window → MCP for Unity that the connection is on.
Claude config file invalidSetup never touches a broken claude_desktop_config.json. Fix the file (backups are in the same folder) and rerun setup.

5. Uninstall

Settings → Apps → ArchMCP → Uninstall. Removes the archmcp-… entries from your Claude config, the Revit add-in and the Photoshop plugin. Your other servers are untouched. Close Revit and Photoshop first (open apps lock the add-in files). The package added to your Unity projects is not removed, because your projects may be under version control; if you want it gone, press Remove for the project in the panel before uninstalling. The Claude config backups made at install (…archmcp-backup-…) are kept.
